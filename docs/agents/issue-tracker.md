# Issue tracker

This repository's issues are tracked in [`mathiasflaatt/tdc-screens`](https://github.com/mathiasflaatt/tdc-screens/issues). Issue descriptions are the source for ticket scope and acceptance criteria; check the issue before reviewing or continuing ticket work.

With GitHub CLI access, fetch one issue with:

```sh
gh issue view <number> --repo mathiasflaatt/tdc-screens
```

To find open work, use:

```sh
gh issue list --repo mathiasflaatt/tdc-screens --state open
```

If GitHub access is unavailable, state that the issue could not be checked and base conclusions only on the material available in the repository.
